# Hariyali Krishi Kendra - Agriculture Retail & Farmer Invoicing

[![PWA Ready](https://img.shields.io/badge/PWA-Offline%20Ready-success)](sw.js)
[![HTML5 & Vanilla JS](https://img.shields.io/badge/Stack-HTML5%20%7C%20Vanilla%20JS-E34F26?logo=html5&logoColor=white)](https://developer.mozilla.org/)

A lightweight, offline-capable Progressive Web Application (PWA) designed for agricultural input retail stores (fertilizers, certified seeds, pesticides) and rural Krishi Seva Kendras.

---

## 1. Problem Statement

Retail agro-dealers in rural farming hubs face:
- Frequent internet outages disrupting billing and inventory lookups.
- Complex farmer credit management (Kisan Khata) during sowing seasons.
- High costs and hardware requirements of desktop accounting software.

**Hariyali Krishi Kendra** offers a zero-dependency, mobile-first web app that operates seamlessly offline and online.

---

## 2. Key Features

- **POS Billing & Invoice Generator:** Fast cash/credit billing with print templates for A4 and thermal printers.
- **Fertilizer & Seed Catalog:** Batch-wise inventory management for Urea, DAP, NPK, and hybrid seeds.
- **Kisan Khata (Farmer Credit Ledger):** Village-wise farmer ledger with partial payment logging.
- **Live Mandi Bhav Ticker:** Daily market prices for major crops.
- **Offline PWA Support:** Built-in service worker cache for offline rural operations.

---

## 3. Getting Started

```bash
# Clone the repository
git clone https://github.com/jagmohan-kurmi/haryali-krishi-kendra.git
cd haryali-krishi-kendra

# Start local server
node server.js
# or use Python
python -m http.server 8080
```
Open `http://localhost:8080` in your web browser.
